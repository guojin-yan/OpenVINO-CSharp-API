# {NUGET_ID}

Native OpenVINO GenAI **{VERSION}** runtime libraries for **{PLATFORM_LABEL}**.

This package is a companion native runtime package for
[`JYPPX.OpenVINO.CSharp.API`](https://www.nuget.org/packages/JYPPX.OpenVINO.CSharp.API/).
It ships OpenVINO Core, OpenVINO GenAI C API, tokenizers, frontends, device
plugins, and runtime dependencies in the same standard .NET layout used by
the core runtime packages: `runtimes/{RID}/native/`.

该包是 `JYPPX.OpenVINO.CSharp.API` 的 OpenVINO GenAI 原生运行时配套包。
它包含 OpenVINO Core、OpenVINO GenAI C API、tokenizers、frontends、设备插件和运行时依赖，
并使用与基础 runtime 包一致的标准 .NET 布局：`runtimes/{RID}/native/`。

```sh
dotnet add package JYPPX.OpenVINO.CSharp.API
dotnet add package {NUGET_ID}
```

Install this runtime package only when you use `OpenVinoSharp.GenAI`. Core
OpenVINO APIs work with the normal `OpenVINO.runtime.*` packages and do not
load `openvino_genai_c`.

仅在使用 `OpenVinoSharp.GenAI` 时安装此 runtime 包。基础 OpenVINO API 只需要普通
`OpenVINO.runtime.*` 包，不会加载 `openvino_genai_c`。

For .NET 5+ consumers the binaries are auto-resolved. For .NET Framework 4.x
consumers the included `build/net/{NUGET_ID}.props` copies runtime files to the
output directory.
