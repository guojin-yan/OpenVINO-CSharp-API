# OpenVINO C# API Documentation / 文档首页

OpenVINO C# API provides managed .NET wrappers for the OpenVINO C API and the optional OpenVINO GenAI C API.

OpenVINO C# API 为 OpenVINO C API 和可选的 OpenVINO GenAI C API 提供 .NET 托管封装。

## Runtime Packages / Runtime 包

Install only a core OpenVINO runtime package when using the basic inference APIs. Install a GenAI runtime package only when calling `OpenVinoSharp.GenAI`.

只使用基础推理 API 时，只需要安装基础 OpenVINO runtime 包。只有调用 `OpenVinoSharp.GenAI` 时才需要安装 GenAI runtime 包。
