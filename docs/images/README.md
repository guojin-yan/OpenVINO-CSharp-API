# Images Directory

Place your documentation images here:

- `logo.svg` or `logo.png` - Site logo (recommended: 32x32px or 64x64px)
- `favicon.ico` - Browser tab icon (recommended: 32x32px)
- Other documentation images

## Recommended Logo Style

- Format: SVG (preferred) or PNG with transparent background
- Color: Should work well on both light and dark backgrounds
- Size: 32x32px for favicon, 120x40px for navbar logo
